## Django
## homework
#### Пагинация:
	Реализован постраничный вывод пользователей (по 10 записей на страницу). 
	Ссылки пагинации сохраняют параметры фильтрации.
	Использован Paginator для корректной работы.
	
#### Фильтрация данных:
	Фильтрация реализована по полям:
	Город (city)
	Фамилия (last_name)
	Параметры передаются через GET-запросы и сохраняются при переходе по страницам.

#### Шаблонные фильтры:
	capfirst — для отображения имен с заглавной буквы.
	date — для форматирования даты рождения в формате дд.мм.гггг.
	
#### Менеджеры моделей:
	Создан пользовательский QuerySet с методом from_spb() для фильтрации пользователей из Санкт-Петербурга.
	
#### Все ключевые функции проекта покрыты тестами. Тесты проверяют:
	Автогенерацию полей при создании пользователей.
	Создание логов через сигналы.
	Корректную работу фильтрации и пагинации.
	Наличие шаблонов и правильные коды ответов.
